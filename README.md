Santo açucar 📋🍔

Este projeto consiste em um sistema de **cardápio digital**, desenvolvido com o objetivo de apresentar diferentes pratos e produtos de forma organizada, simples e intuitiva.

A aplicação permite visualizar os produtos disponíveis, suas informações e seus respectivos preços.

## 🎯 Objetivo

O objetivo do projeto é desenvolver uma interface de cardápio moderna e responsiva, facilitando a visualização dos produtos e proporcionando uma boa experiência para o usuário.

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## 🖥️ Funcionalidades

* 📋 Exibição dos produtos
* 🍔 Organização dos itens por categorias
* 💰 Exibição dos preços
* 📱 Layout responsivo
* 🎨 Interface simples e intuitiva
